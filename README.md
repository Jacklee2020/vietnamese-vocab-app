## 🎯 功能详解

### 🃏 今日学习（卡片记忆法）

1. 首页显示**今日目标**（新词 + 复习）与**连续打卡天数**，点「开始今日学习」进入卡片队列；
2. 卡片正面是**越南语单词**（带分类标签），点「🔊 发音」或点卡片：先听、再**翻转查看中文释义**；
3. 回忆后点「✓ 认识」或「✗ 不认识」——**不认识的单词自动收进生词本**，后续按间隔重复出现；
4. 学完一组会展示本次新词与回顾，帮你复盘。

> 💡 **技巧**：开启「设置 → 自动发音」后，卡片出现即自动朗读，配合跟读效果最好。

### 📝 自测闯关（三种题型）

| 题型 | 玩法 | 适合 |
| --- | --- | --- |
| ✍️ 四选一 | 看越南语，从 4 个中文中选正确释义 | 快速刷词、检测词汇量 |
| 🔊 听音 | 听发音，选择对应的中文释义 | 练听力辨音 |
| ⌨️ 拼写 | 看中文，拼出越南语 | 练书写拼写 |

测验前可选**范围**（已学 / 生词本 / 全部）与**题数**（10 / 20 / 50）。结束显示正确率与错词清单，错词可一键加入生词本。

### 📕 生词本

- 学习中「✗ 不认识」的单词、词表里手动收藏（☆）的单词都会出现在这里；
- 点单词可**听发音**、复习释义；完全记住的点「⭐ 标记已掌握」移出；不需要的点「✕」移除。

### 📚 词表浏览与搜索

- 按 **12 大类**分类浏览，也可查看「全部词汇」；
- 顶部搜索框支持**越南语、中文**模糊搜索；
- 点单词弹出详情卡：发音、分类、学习状态（未学 / 学习中 / 已掌握）、加入生词本。

### ⚙️ 设置（「👤 我的」页）

| 设置项 | 说明 |
| --- | --- |
| 每日新词数 | 10 / 20 / 50 / 100，按时间灵活调整 |
| 发音语速 | 慢（0.8×）/ 正常（1×）/ 快（1.2×） |
| 自动发音 | 展示单词时自动朗读 |
| 深色模式 | 夜间背词护眼 |

### 💾 数据备份与恢复

学习进度（已学、生词本、打卡、设置）保存在**当前设备浏览器**中。换机 / 清理缓存前请先备份：

1. 「👤 我的 → 数据」点**导出**，下载 JSON 备份文件；
2. 新设备打开 App 点**导入**选择该文件，进度即恢复；
3. 「清空」可删除本机全部学习记录（有二次确认）。

> ⚠️ **注意**：清空浏览器缓存、无痕模式、清除网站数据都会导致进度丢失，务必先导出。

## ❓ 常见问题

**Q：为什么点了发音没有声音？**
App 调用手机系统的越南语语音，需要先下载语音包：
- **iPhone**：设置 → 辅助功能 → 朗读内容 → 声音 → 越南语（Tiếng Việt），下载语音；
- **Android**：设置 → 系统 → 语言与输入法 → 文字转语音（TTS），下载越南语语音数据；
- 同时检查手机是否静音或开了勿扰模式。

**Q：换手机 / 清理浏览器数据，进度会丢吗？**
会。App 没有云端账号，进度只存在本机。换设备前先「导出」备份，新设备「导入」恢复。

**Q：离线能用吗？**
能。首次联网打开后词库与页面自动缓存，之后断网、飞行模式均可正常学习。

**Q：我的学习数据安全吗？**
安全。App 是纯前端页面，**没有任何服务器**，单词与进度均不出本机，不存在上传或泄露。

**Q：想改词库怎么办？**
词库源文件是 `词库_合并版.csv`（`序号, 分类, 越南语, 中文`），用 Excel / 表格软件编辑后重新生成即可。

**Q：有些单词不想背，能删掉吗？**
能。词表页点开单词 → 点「🙈 不再背诵」，该词就不会再出现在学习、测验、生词本和词表中（统计也会自动调整）；误删了可在词表页底部「已隐藏词汇」里一键恢复。删除记录存在本机，导出/导入备份时一并保存。

## 📖 学习建议

- **小步快跑**：新手建议每日 10~20 词起步，坚持连续打卡，比一次贪多更有效；
- **跟读出声**：开启自动发音，每张卡片跟读 2 遍，练语感也练听力；
- **复习优先**：先完成首页「待复习」，再做新词；
- **多题型轮换**：四选一刷量 → 听音辨词 → 拼写默写，循环巩固；
- **场景串联**：学完「餐饮」类，试着用「口语短句」造几句点餐对话；
- **善用生词本**：每天睡前把生词本过一遍。

> 🧠 **记忆原理**：App 按间隔复习自动安排——当天新词、次日复现、隔天再测，符合遗忘曲线，坚持 2~4 周即可明显见效。
